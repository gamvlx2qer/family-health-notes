# 节能环保  “住院每日清单”实现无纸化查询

> 更新时间：2026-09-17 (UTC+8)

您知道热敏纸吗？它是医院给住院患者打印每日住院清单时必不可少的物品。柳州市人民医院作为一家实力强劲的三级甲等综合医院，住院人数较多，且住院患者每天的详细用药、治疗等信息都通过住院清单体现，因此热敏纸的使用有增无减，这无形中既造成资源的浪费，也损耗了不少木材。

        节能环保不仅仅是一句口号，更应该付诸实践，为减少热敏纸的使用，节约资源，我院微信公众号推出“住院每日清单查询”功能。此功能上线后，医院每个月可节省热敏纸近2000卷，相当于少砍伐13棵树，真正为环保出了一份力。

        “住院每日清单查询”功能可以使用微信直接查询住院期间每日清单，只需患者及家属关注公众号并绑定住院信息即可进行查询。微信查询住院清单，让患者及家属方便、快捷地掌握住院费用情况；绑定住院信息时验证患者手机号，有效保证住院费用信息安全不泄露；微信查询清单取代纸质清单，更环保，避免丢失及纸质清单丢失后信息泄露。无智能手机或无微信的患者，可到住院部一楼大厅，在自助查询机上使用办理入院时的就诊卡来查询住院每日清单。

        本院微信公众号还有很多功能：门诊预约挂号、门诊费用微信支付、检验报告查询、智能导诊、医生介绍、出诊安排查询、健康百科、来院路线等，为患者提供更便捷、更流畅的就诊流程。

        如何查询住院清单？只需要以下几个步骤：

        1、关注微信公众号

        a) 扫码关注

        b) 在微信“添加朋友”→“公众号”→搜索“柳州市人民医院”。

        2、注册本院账号

        首次使用本院公众号的患者，进入“柳州市人民医院”微信公众号 → 信息查询 → 个人中心 → 登录 → 快速注册 → 根据提示依次输入手机号码、密码、验证密码、图形验证码、获取手机验证码 → 注册成功。

        3、绑定住院信息

        进入“柳州市人民医院”微信公众号 → 信息查询 → 个人中心 → 住院号管理 → 添加住院号 →根据提示依次输入姓名、住院号、手机号码、验证码，手机号码需与患者办理入院登记的手机号一致。添加成功后，在住院号管理中可看到住院信息。

       4、查询住院清单

        进入“柳州市人民医院”微信公众号 → 信息查询 → 住院日清单 → 选择住院患者 → 选择需查询的清单日期 → 住院每日清单显示。

       注意：

        ①已关注本院微信公众号并使用过门诊预约挂号功能的患者，直接看步骤3。

        ②非首次查询住院每日清单的患者，直接看步骤4。

        ③请确保入院登记时手机号码为本人正常使用的号码。微信绑定住院信息时，将给该手机号码发送验证短信，验证通过后才可查询住院每日清单。该手机号和验证码是查住院每日清单的重要依据，请妥善保管。

        ④对于不会使用手机微信的患者，我院住院部一楼出院接待处可提供查询“住院每日清单”的服务。
