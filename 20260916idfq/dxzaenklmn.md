# 秋高气爽遭遇秋季腹泻，宝妈如何应对？

> 更新时间：2026-09-16 (UTC+8)

"在秋天，水和蓝天一样的清凉。天上微微有些白云，水上微微有些波皱"，这是老舍笔下《济南的秋天》！这么棒的天气，小宝宝们可以多多出来撒欢，晒晒太阳，是补钙的大好时机哦。可是如果宝宝得了秋季腹泻，不少新手妈妈见到宝宝腹泻的状况，会手足失措，心急如焚。其实，秋季腹泻也没那么可怕，今天，济南市妇幼保健院急诊科就来说一说秋季腹泻。
1秋季腹泻简述
多发生在秋冬季

轮状病毒感染引起

多见于6-24个月婴幼儿

多以发热，上感样症状起病

吐先于泻

便次多、量多、水分多，黄色水样或蛋花样便

可自愈，病程3-8天

可有全身症状

2秋季腹泻的护理
目前没有十分有效的抗病毒药物，应注重宝宝腹泻期间的护理，不要盲目地给宝宝用药。

2.1 及时补液：秋季腹泻以发烧、呕吐、频繁、大量的稀水便为主，所以宝妈要及时给宝宝补液，否则可能导致宝宝电解质丢失甚至脱水。少量、多次给宝宝喝加入少许糖、盐的水可以纠正电解质丢失，也可以选择口服补液盐进行补液。宝宝喝水后马上呕吐，无法在家中完成补液时应带宝宝去医院就诊。

2.2 臀部护理：宝宝腹泻次数多，屁屁周围的皮肤会有损伤，宝妈要细心呵护宝宝的屁屁，腹泻后及时更换尿裤，用温水冲洗干净或用纱布蘸温水轻轻擦拭，晾干后再包裹尿裤，以免宝宝出现红屁股。**我院自制剂鞣酸软膏用来预防红屁股效果很棒哦（不少宝妈亲测，效果秒杀海外代购大牌，无激素，可放心使用）。**

****

2.3 进食与喂养：应暂时避免添加新的辅食，在宝宝已经顺利添加的辅食中选择易消化且细软的食物给宝宝吃，以免食物不耐受加重腹泻。**母乳喂养的宝宝在腹泻期间继续母乳喂养，非母乳喂养的宝宝在腹泻期间更换为****无乳糖配方奶粉进行喂养。**
特别提醒宝宝在秋季发生腹泻虽然大多为轮状病毒感染，但也不排除细菌感染或牛奶蛋白过敏等其他原因导致的腹泻，所以不确定的话还是要带宝宝就医，化验一下便便才好。3秋季腹泻的预防

3.1 提倡母乳喂养，母乳中富含免疫球蛋白，有助于增强婴幼儿胃肠道功能。

3.2 处理食物和进食前、换尿布后彻底洗手。

3.3 餐具、炊具用前消毒，尤其是做辅食用的餐具，容易忽略如菜板、过滤纱布、榨汁机、各种容器等。

3.4 清理呕吐物、粪便、受污染的地方和东西时最好戴手套，并用含氯消毒剂彻底清洁消毒，事后彻底洗手。

3.5 避免宝宝和腹泻的人员密切接触。

3.6 口服轮状病毒疫苗预防。6个月-3岁的宝宝，可在每年的7-9月份带宝宝去社区口服疫苗，每年一次。
